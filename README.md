## 🚀 Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/aanand058/Personal-Portfolio.git
   cd Personal-Portfolio
   ```

2. **Open the project**
   - Open `index.html` in your browser
   - Or use a local server:
     ```bash
     # Python
     python -m http.server 8000
     # Node.js (if http-server installed)
     npx http-server
     ```

3. **View the website**
   - Go to `http://localhost:8000` (or your chosen port)

## 💻 Usage

- Edit the HTML to update your About, Education, Experience, Projects, and Certifications.
